# 東洋医療専門学校 DXセミナー ITパスポート模擬テストアプリ

東洋医療専門学校による、ITパスポートの無料オリジナル模擬テストアプリです。

## 機能

- 100問・4択式・ストラテジ35問／マネジメント20問／テクノロジ45問
- 本番想定の120分試験モードと時間無制限の練習モード
- 解答の端末内保存、タイマー、自動採点
- 分野別の結果、全問解説、間違えた問題の絞り込み
- CSVでの結果保存、印刷
- 学校案内・救急救命士学科・オープンキャンパス・資料請求リンク

## 技術構成

静的HTML + CSS + JavaScript。追加のビルドコマンドや外部DBは不要です。
Vercelでは**プロジェクトのRoot Directoryを `itpassport-landing`** に設定してください。

## 注意

- このアプリは独自の非公式学習教材です。情報処理推進機構（IPA）の公式試験問題ではありません。
- 結果の正答率は本試験のIRT方式による評価点ではありません。
- 解答の保存先はブラウザのlocalStorageです。個人情報を入力・外部送信する仕組みはありません。
- 学校のカリキュラムへの正式導入や資格取得保証を宣言するものではありません。
